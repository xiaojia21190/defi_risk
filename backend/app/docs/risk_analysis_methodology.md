# DeFi风险分析系统 - 风险分析方法论

## 1. 风险评估框架概述

DeFi风险分析系统采用多维度风险评估框架，综合考量不同类型的风险因素，为用户提供全面的风险评估。系统基于加权评分模型，将各类风险因素根据重要性赋予不同权重，计算得出最终的风险评分。

### 基本风险评分体系

- **评分范围**: 0-100
- **风险等级**:
  - 0-20: 极低风险
  - 21-40: 低风险
  - 41-60: 中等风险
  - 61-80: 高风险
  - 81-100: 极高风险

### 风险维度权重分配

系统根据风险类型的重要性分配权重，配置于`risk_weights.yaml`：

```yaml
RISK_WEIGHTS:
  MARKET: 0.30        # 市场风险
  SMART_CONTRACT: 0.20 # 智能合约风险
  LIQUIDITY: 0.20      # 流动性风险
  PROTOCOL: 0.15       # 协议风险
  CORRELATION: 0.10    # 相关性风险
  REGULATORY: 0.05     # 监管风险
```

## 2. 风险分析方法详解

### 2.1 市场风险分析 (MarketRiskAnalyzer)

市场风险关注资产价格波动、市场趋势和宏观经济因素对DeFi投资的影响。

#### 主要风险因子：

1. **价格波动风险**
   - **计算方法**: 基于历史价格数据计算波动率
   - **评分标准**:
     - <10%: 低风险(20-40分)
     - 10-30%: 中等风险(41-60分)
     - 30-50%: 高风险(61-80分)
     - >50%: 极高风险(81-100分)

2. **市值风险**
   - **计算方法**: 基于资产市值规模评估
   - **评分标准**:
     - >100亿美元: 低风险(20-40分)
     - 10-100亿美元: 中低风险(30-50分)
     - 1-10亿美元: 中等风险(50-70分)
     - <1亿美元: 高风险(70-90分)

3. **趋势风险**
   - **计算方法**: 分析价格趋势和动量指标
   - **指标**: 移动平均线交叉、RSI、MACD等
   - **评分标准**: 根据趋势强度和持续性评分

4. **市场情绪风险**
   - **数据来源**: 社交媒体、新闻情绪分析
   - **计算方法**: AI情绪分析模型评估市场情绪
   - **评分标准**: 基于正面/负面情绪分布

#### 计算公式：

```
市场风险评分 = (价格波动风险 * 0.4) + (市值风险 * 0.3) + (趋势风险 * 0.2) + (市场情绪风险 * 0.1)
```

### 2.2 智能合约风险分析 (SmartContractRiskAnalyzer)

智能合约风险评估协议代码安全性、审计状态和历史漏洞等因素。

#### 主要风险因子：

1. **审计状态**
   - **数据来源**: 公开审计报告、DeFiSafety评级
   - **评分标准**:
     - 多次知名机构审计且无重大问题: 低风险(20-30分)
     - 单次审计且已修复问题: 中低风险(30-50分)
     - 有审计但存在未修复问题: 中高风险(50-70分)
     - 无审计或有严重漏洞历史: 高风险(70-90分)

2. **代码开源度**
   - **评估内容**: 代码公开性、文档完整性
   - **评分标准**:
     - 完全开源且文档详尽: 低风险(20-40分)
     - 部分开源或文档不完整: 中等风险(40-70分)
     - 闭源或无文档: 高风险(70-90分)

3. **历史安全事件**
   - **数据来源**: 历史黑客攻击、漏洞记录
   - **评分标准**:
     - 无安全事件: 低风险(20-40分)
     - 小型安全事件已修复: 中等风险(40-60分)
     - 重大安全事件: 高风险(60-90分)

4. **合约复杂度**
   - **评估内容**: 代码复杂性、交互复杂度
   - **评分标准**: 基于合约交互数量、函数复杂性评分

#### 计算公式：

```
智能合约风险评分 = (审计状态风险 * 0.4) + (代码开源度风险 * 0.2) + (历史安全事件风险 * 0.3) + (合约复杂度风险 * 0.1)
```

### 2.3 流动性风险分析 (LiquidityRiskAnalyzer)

流动性风险关注资产的交易深度、流动性池稳定性和提取/退出风险。

#### 主要风险因子：

1. **交易量/市值比率**
   - **计算方法**: 24小时交易量与市值的比率
   - **评分标准**:
     - >20%: 低风险(20-40分)
     - 10-20%: 中低风险(40-50分)
     - 5-10%: 中等风险(50-70分)
     - <5%: 高风险(70-90分)

2. **流动性池集中度**
   - **计算方法**: 分析流动性提供者的集中程度
   - **评分标准**: 基于最大LP持有比例评分

3. **滑点分析**
   - **计算方法**: 模拟大额交易对价格的影响
   - **评分标准**: 基于100万美元交易的预期滑点

4. **锁仓比例**
   - **计算方法**: 锁定资产占总供应量的比例
   - **评分标准**: 基于锁定比例和锁定期评分

#### 计算公式：

```
流动性风险评分 = (交易量/市值比率风险 * 0.35) + (流动性池集中度风险 * 0.25) + (滑点风险 * 0.25) + (锁仓比例风险 * 0.15)
```

### 2.4 协议风险分析 (ProtocolRiskAnalyzer)

协议风险评估DeFi协议的治理机制、经济模型和技术架构。

#### 主要风险因子：

1. **治理模型风险**
   - **评估内容**: 去中心化程度、治理参与度
   - **评分标准**:
     - 完全去中心化且活跃治理: 低风险(20-40分)
     - 部分去中心化: 中等风险(40-60分)
     - 高度中心化: 高风险(60-90分)

2. **经济模型风险**
   - **评估内容**: 通证经济模型可持续性
   - **评分标准**: 基于通证分配、通胀设计评分

3. **协议年龄和规模**
   - **计算方法**: 基于协议运行时间和TVL评估
   - **评分标准**:
     - >2年且TVL>10亿: 低风险(20-40分)
     - 1-2年或TVL 1-10亿: 中等风险(40-60分)
     - <1年或TVL<1亿: 高风险(60-80分)

4. **开发活跃度**
   - **数据来源**: GitHub提交活动、开发者数量
   - **评分标准**: 基于开发活跃度和社区支持评分

#### 计算公式：

```
协议风险评分 = (治理模型风险 * 0.3) + (经济模型风险 * 0.3) + (协议年龄和规模风险 * 0.25) + (开发活跃度风险 * 0.15)
```

### 2.5 相关性风险分析 (CorrelationRiskAnalyzer)

相关性风险评估DeFi资产组合的多样化程度和风险集中度。

#### 主要风险因子：

1. **资产相关性**
   - **计算方法**: 资产间价格相关性矩阵
   - **评分标准**:
     - 平均相关性<0.3: 低风险(20-40分)
     - 相关性0.3-0.7: 中等风险(40-70分)
     - 相关性>0.7: 高风险(70-90分)

2. **链相关性**
   - **计算方法**: 跨链资产分布情况
   - **评分标准**: 基于资产在不同区块链的分布评分

3. **协议集中度**
   - **计算方法**: 单一协议占比分析
   - **评分标准**: 基于最大协议占比评分

4. **代币类型多样性**
   - **计算方法**: 不同类型代币(稳定币、治理币等)的分布
   - **评分标准**: 基于代币类型分布评分

#### 计算公式：

```
相关性风险评分 = (资产相关性风险 * 0.4) + (链相关性风险 * 0.2) + (协议集中度风险 * 0.3) + (代币类型多样性风险 * 0.1)
```

## 3. 综合风险评估

系统将各类风险分析器的结果进行加权整合，计算出最终的综合风险评分。

### 综合风险计算

```python
def calculate_overall_risk(risk_results):
    """计算综合风险评分"""
    total_weight = sum(settings.RISK_WEIGHTS.values())
    weighted_score = 0

    for risk_type, result in risk_results.items():
        weight = settings.RISK_WEIGHTS.get(risk_type, 0)
        weighted_score += result.score * weight / total_weight

    return weighted_score
```

### 风险建议生成

系统基于风险评分和风险因子，使用AI服务生成针对性的风险缓解建议：

```python
async def get_recommendations(self, risk_factors):
    """获取风险缓解建议"""
    recommendations = []

    # 基于高风险因子生成建议
    high_risk_factors = [f for f in risk_factors if f.score > 70]
    for factor in high_risk_factors:
        recommendations.append(f"降低{factor.name}风险: {factor.description}")

    # 使用AI服务增强建议
    if self.ai_service:
        ai_recommendations = await self.ai_service.analyze_with_predictor(
            "risk_recommendations",
            {"risk_factors": [f.__dict__ for f in risk_factors]}
        )
        recommendations.extend(ai_recommendations.get("recommendations", []))

    return recommendations
```

## 4. 风险监控体系

除了静态风险评估，系统还提供动态风险监控功能。

### 监控点生成

```python
async def get_monitoring_points(self, risk_factors):
    """获取监控点"""
    monitoring_points = []

    # 根据风险因子生成监控点
    for factor in risk_factors:
        if factor.score > 60:  # 中高风险因子需要监控
            monitoring_points.append(f"监控{factor.name}指标的变化趋势")

    # 添加基础监控项
    monitoring_points.extend([
        "关注价格波动超过10%的情况",
        "监控协议TVL变化趋势",
        "关注社交媒体上的负面情绪变化"
    ])

    return monitoring_points
```

### 市场场景模拟

系统支持不同市场场景下的风险模拟，包括：

- 市场崩盘场景
- 流动性冲击场景
- 协议漏洞利用场景
- 监管打击场景

每种场景使用不同的模型参数，模拟在极端情况下的投资组合表现。

## 6. 风险评分解释性

系统强调风险评估的可解释性，为每个风险评分提供：

1. **风险因子明细**：列出所有风险因子及其贡献
2. **数据支持**：提供支持评分的关键数据点
3. **历史趋势**：展示风险评分的历史变化
4. **同类对比**：与同类资产/协议的风险比较

通过这些解释性功能，用户能够清晰理解风险来源，做出更明智的投资决策。
